# Yumeiro 0.1.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans task-by-task. Steps use checkbox syntax.

**Goal:** Make all existing Pixiv plugin features real and release verified v0.1.2.

**Architecture:** Retain the client/service/configuration boundaries. Add bounded runtime state, centralized safety and an awaited sender; the command and LLM tool share orchestration. Pages retain their visual design and bind to the completed routes.

**Tech Stack:** Python 3.10+, AstrBot Star/Pages APIs, httpx, pytest, vanilla JavaScript/CSS/HTML.

**Spec:** docs/superpowers/specs/2026-09-24-v012-approved-scope.md

## Global Constraints
- No real Pixiv credentials in tests or logs.
- R-18 and R-18G filters enabled by default; IDs and caches cannot bypass safety.
- Keep changes within existing advertised features.
- Limit every network pagination loop and every image request; count successful sends only.
- Release only after fresh verification and independent review; no force push.
